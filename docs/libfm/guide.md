# libfm – the behaviour behind PCManFM

libfm is the library that supplies PCManFM with file operations, trash, thumbnails and “open with”. `libfm.conf` decides **how a file manager
behaves**; the look is handled by [PCManFM](../pcmanfm/index) and [GTK](../gtk3/index).

:::{note}
The file carries the header “Autogenerated file, don't edit”. That comes from libfm itself and refers to the **program UI**: changing settings
in the PCManFM dialog makes libfm rewrite the file. You can edit it by hand just as well – do it while the file manager is closed.
:::

## Important settings

| Key | Value | Effect |
| --- | --- | --- |
| `single_click` | `0` | Double-click opens (not single click) |
| `use_trash` | `1` | Delete moves to the trash |
| `confirm_del` | `1` | Permanent delete asks for confirmation |
| `confirm_trash` | `0` | Moving to the trash does not ask |
| `no_usb_trash` | `1` | No trash on USB drives (no `.Trash` folder) |
| `quick_exec` | `1` | Executables start without a prompt |
| `terminal` | `kitty` | Programs that need a terminal open in Kitty |
| `si_unit` | `0` | Sizes in steps of 1024 (KiB), not 1000 |
| `thumbnail_max` | `2048` | Thumbnails for files up to 2 MB |
| `show_thumbnail` / `thumbnail_size` | `1` / `128` | Preview images, 128 px |
| `force_startup_notify` | `1` | Startup feedback when opening programs |
| `smart_desktop_autodrop` | `1` | Dropping on application icons starts them with the file |

Icon sizes: `big_icon_size=48` (icon view), `small_icon_size=24` (list), `pane_icon_size=24` (side panel).

## Side panel (“places”)

The `[places]` section decides what appears on the left: home, desktop, trash, applications and unmounted volumes are **on**;
the filesystem root (`places_root`), computer and network are **off**.

## Typical changes

```ini
# ~/.config/libfm/libfm.conf
single_click=1          # single click opens
terminal=foot           # a different terminal
confirm_trash=1         # also ask when moving to the trash
places_root=1           # show "/" in the side panel
```

## Troubleshooting

- **A change disappears:** PCManFM was open and rewrote the file on exit – close it first, then edit.
- **No thumbnails:** `show_thumbnail=1`; video thumbnails need `ffmpegthumbnailer` (optional dependency of the PCManFM package).
- **Wrong terminal:** adjust `terminal=`; otherwise “run in terminal” uses Kitty.

## Customise and reset

`~/.config/libfm` is a link to your editable copy in
`~/.local/share/arch-dotfiles/config/libfm/`. Change anything there; `pacman -Syu` does **not** overwrite your
edits. When an update ships new defaults they appear as a `.pacnew` file next to yours and you merge what you want
(`aco sync` merges, `aco status` shows the state). To go back to the shipped defaults, `aco deactivate libfm` restores the
previous settings and `aco install libfm` activates the package defaults again.
