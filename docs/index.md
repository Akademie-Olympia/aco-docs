# ACO Components

::::{div} aco-hero
**Documentation for the small ACO components – one site instead of nine.**
::::

These components consist of only a few configuration files each. Their repositories hold the configuration and the package recipe; their
documentation lives here so that the ecosystem needs one Read the Docs project instead of nine. The larger components
([Hyprland](https://aco-hypr.readthedocs.io/en/latest/), [Neovim](https://aco-nvim.readthedocs.io/en/latest/),
[tmux](https://aco-tmux.readthedocs.io/en/latest/), [Zsh](https://aco-zsh.readthedocs.io/en/latest/), [Vim](https://aco-vim.readthedocs.io/en/latest/),
[Kitty](https://aco-kitty.readthedocs.io/en/latest/), [Ghostty](https://aco-ghostty.readthedocs.io/en/latest/)) keep their own sites.
