# aco-docs

Documentation of the small [ACO](https://aco-arch-dotfiles.readthedocs.io/en/latest/) components in **one** Read the Docs project:
**Waybar, Wallpaper, Fuzzel, Foot, Yazi, PCManFM, libfm, GTK 3 and GTK 4.**

These components consist of only a few configuration files each, so a Read the Docs project per repository would be mostly overhead.
Their repositories keep the configuration and the package recipe; the documentation lives here. The larger components (Hyprland, Neovim, tmux, Zsh,
Vim, Kitty, Ghostty) keep their own sites. Every site's sidebar lists all components and links straight to the right place.

**Published at <https://aco-docs.readthedocs.io/en/latest/>**

## Layout

```text
docs/
  index.md              overview of the small components
  <component>/          index, guide, design, installation, configuration
  _configs/<component>/ copies of the shipped configuration files (generated)
  _aco/                 shared documentation kit (copied from the hub, do not edit)
scripts/sync-configs.py copies the configuration files from the component repositories
```

## Working on the documentation

```bash
# with all repositories side by side (see aco-arch-dotfiles/scripts/clone-repos.sh)
python3 scripts/sync-configs.py          # refresh docs/_configs from the component repositories
python3 ../aco-arch-dotfiles/scripts/gen-design.py   # regenerate the design/dependency pages
pip install -r docs/requirements.txt
sphinx-build -W --keep-going -b dirhtml docs docs/_build
```

- `guide.md` pages are hand-written; `design.md` pages are generated by `aco-arch-dotfiles/scripts/gen-design.py` from the component `PKGBUILD`s – do not edit them.
- `docs/_aco/` comes from the hub (`scripts/sync-docs-kit.py`); change it there.
- All documentation is written in English.

## Read the Docs setup

Create **one** project named `aco-docs` from this repository (configuration file: `.readthedocs.yaml`). It builds with warnings as errors.
